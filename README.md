# SubTracker

AI-powered subscription and free trial tracker built using:

- React
- Express.js
- Gmail API
- Prisma ORM
- SQLite

## Features

- Google OAuth login
- Gmail subscription email detection
- Trial extraction
- Price detection
- Auto-renew detection
- Subscription database storage

## Tech Stack

Frontend:
- React
- Vite

Backend:
- Node.js
- Express
- Prisma
- Gmail API

## Setup

1. Clone repo
2. Install dependencies
3. Add .env
4. Run backend
5. Run frontend
